# Intelligence Dashboard

Read-only web control plane for the multimodal video intelligence backend.

## Setup

1. Install Node.js 18+ and npm.
2. Install dependencies:

```bash
npm install
```

3. Optional API base override:

```bash
echo "VITE_API_BASE=http://localhost:8000" > .env
```

4. Run dashboard:

```bash
npm run dev
```

## Key Views

- Video Intelligence Panel
- Timeline Intelligence View
- Person Tracking View
- Semantic Understanding Panel
- Prediction Panel
- Graph Explorer
